本週社群重點洞察
遊戲體驗本週玩家負評集中在匹配機制與遊戲平衡兩大核心問題：單排玩家頻繁遭遇連敗且被配對到組隊玩家，導致極度不滿情緒；愛麗絲英雄強度失衡（勝率達100%）及伺服器高延遲問題嚴重影響遊戲公平性，需立即處理以避免玩家流失。
活動反應活動設計缺乏事前說明導致玩家體驗不佳，無好友玩家每日完成任務卻無法達成目標，浪費時間後產生負面觀感，建議優化活動參與門檻說明或降低社交要求。
Bug回報遊戲穩定性問題浮現，玩家遭遇短時間內多次閃退且無法開啟特定模式，而其他遊戲正常運行，需技術團隊緊急排查客戶端問題。
客服問題第三方登入（臉書）帳號救援機制不足，玩家因平台停用無法登入時，官方未提供有效解決方案而直接推責，需建立更完善的帳號綁定與救援流程。
