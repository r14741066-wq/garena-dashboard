本週社群重點洞察
遊戲體驗匹配與配對機制是本週最大爭議點，玩家普遍反映隊友素質差距大、對手排位歷史明顯較高導致連敗，加上英雄芽芽設計過於簡化缺乏操作深度，以及檢舉機制形同虛設，多位玩家因遊戲體驗惡化而刪除遊戲，需優先優化matchmaking演算法與檢舉系統有效性。
Bug回報遊戲穩定性問題嚴重，包括載入卡頓、開場動畫卡死、切換帳號功能異常等技術問題頻繁發生，即使在網路與設備正常情況下仍無法順利進行遊戲，直接影響玩家留存率，需立即進行技術修復。
付費體驗玩家對付費機制普遍不滿，認為遊戲過度著重儲值、單一角色定價過高（逾600元）、元寶幣商品長期未更新，且更改基本個人資料也需付費的設計被批評不合理，付費價值感與體驗需重新檢視。
客服問題玩家反映誤判停權與人機對手氾濫等問題向客服求助後遭冷處理，客服回應效率與解決問題的積極度不足，損害玩家信任感。
活動反應玩家期待特定英雄新造型且希望提供免費或可用遊戲內貨幣兌換的選項，顯示對付費造型的價格敏感度高，建議平衡商業與玩家需求。
