本週社群重點洞察
遊戲體驗配對機制是本週最大爭議焦點，玩家強烈不滿段位差距過大、人機充斥及低齡玩家影響遊戲品質，且檢舉系統被認為形同虛設，客服申訴無實際改善行動，已嚴重影響玩家留存意願。角色平衡問題持續惡化，連娛樂模式都受波及，團隊需優先處理配對演算法與檢舉機制的實質改善。
Bug回報網路斷線重連機制設計不當，導致玩家在晉級賽等關鍵場次被阻擋進場並遭扣分，勝場積分異常未發放的問題也持續發生，建議優先修復既有Bug再推出新內容，避免技術問題累積影響玩家信任。
活動反應槓桿活動被玩家認為設計不公平且加速輸分，活動體驗極差未能提升參與熱度。玩家對復刻皮膚有需求但對日常獎勵寶箱內容物評價極低，建議重新檢視活動機制公平性與獎勵價值。
付費體驗玩家認為角色建模品質與定價不成正比，並指責遊戲存在誘導儲值的詐騙行為，付費體驗極差已引發強烈負面情緒，需立即檢視商業模式合理性與透明度。
