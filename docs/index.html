本週社群重點洞察
遊戲體驗玩家集中抨擊匹配機制與隊友素質問題，認為存在刻意讓高排名玩家連敗的設計，且檢舉與評分系統失效，多數玩家質疑官方只重視營收而長期忽視遊戲環境改善，此為本週最嚴重且急需處理的核心爭議。
Bug回報多位玩家回報遊戲卡頓、當機、閃退及開場動畫卡死等技術問題，且問題發生頻率高（每五場有兩場閃退），嚴重影響基本遊玩體驗，技術團隊需立即排查修復以避免玩家大量流失。
付費體驗玩家對高額角色定價（單一角色超過600元）及改名換頭像需付費等機制表達不滿，同時抱怨元寶幣商品更新緩慢，顯示付費內容的價值感與更新頻率未能滿足玩家期待。
客服問題玩家反映遭誤判停權及人機問題被冷處理，客服回應態度消極，顯示客訴處理效率與溝通品質需改善，以避免累積更多負面情緒。
其他出現疑似玩家因連敗情緒崩潰並有自我傷害傾向的留言，建議客服團隊主動關懷追蹤，同時反映遊戲挫敗感過高可能引發玩家心理健康風險。
