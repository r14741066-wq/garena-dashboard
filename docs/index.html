本週社群重點洞察
遊戲體驗玩家集中砲火批評配對與檢舉機制形同虛設，反映隊友素質落差大、檢舉後無實際懲處、信譽積分未扣除等問題，即使儲值後體驗仍未改善，嚴重影響遊戲公平性與留存意願，需優先修正匹配演算法與懲處系統的實際執行力。
Bug回報技術性問題集中在英雄技能觸控失靈、網路判定過於嚴苛導致誤判掛機、錯誤代碼1999-1無法登入、畫面卡頓無法解決等，這些Bug直接阻斷玩家遊玩並引發大量負評，需緊急排查修復以避免玩家流失。
客服問題帳號安全與遺失問題突出，玩家反映帳號遭盜用、登入後帳號消失、半年無法找回等狀況，加上誤檢舉時官方未查證回放，顯示客服處理效率與帳號保護機制需大幅強化。
活動反應進擊的巨人聯名活動獲得玩家高度正面評價，場景與角色設計受讚揚並期待持續舉辦，顯示IP聯名策略成功點燃熱度，可作為未來行銷方向。
付費體驗改名卡僅能透過儲值購買、無法使用遊戲內貨幣，被玩家批評為過度斂財，建議檢視付費項目設計是否過於強制，以平衡商業與玩家觀感。
