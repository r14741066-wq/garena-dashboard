本週社群重點洞察
遊戲體驗玩家集中砲火抨擊配對機制嚴重失衡，頻繁被匹配到場次不足或低素質隊友，導致遊戲體驗極差；同時檢舉系統形同虛設，玩家要求加入敗方MVP保護機制以減緩挫折感，此為本週最嚴重且急需處理的問題。
Bug回報技術問題涵蓋多個層面，包括高階設備仍出現嚴重卡頓、活動預約系統持續報錯導致玩家無法領獎、英雄技能顯示異常，以及回歸帳號無法正常登入，這些問題直接阻礙玩家遊玩與參與活動，需技術團隊優先修復。
活動反應玩家對娛樂模式僅週末開放表達強烈不滿，認為限制遊玩時間反而降低消費意願；回歸活動限制過多也讓玩家感受不到誠意，活動設計未能有效提升玩家黏著度與參與熱情。
付費體驗玩家直指遊戲內容空洞卻收費過高，顯示付費價值與玩家期待存在明顯落差。
客服問題檢舉系統以「未查證」為由駁回申訴，讓玩家對檢舉機制喪失信心，此問題與遊戲體驗類別的檢舉無效抱怨相呼應，顯示客服處理流程需重新檢討。
