本週社群重點洞察
遊戲體驗配對機制成為本週最大爭議，玩家集中抱怨隊友素質極差、新手保護機制失效、以及敵我實力嚴重不均導致連敗，負面情緒已累積至要求停服的程度，需立即優化匹配演算法與新手分流機制。
Bug回報技術問題集中在魔法棋模式強制跳出、伺服器連線失敗、麥克風頻道自動切換導致隱私外洩等功能性異常，影響基本遊戲體驗，需緊急修復以免進一步擴大玩家不滿。
客服問題玩家反映退費後帳號遭鎖定十年且客服兩個月零回應，加上檢舉機制失效，顯示客服處理效率與溝通機制嚴重失能，可能引發更大信任危機。
付費體驗玩家質疑新英雄「強推後削弱」的商業模式不公平，且認為不課金玩家在賽季初處於明顯劣勢，付費平衡性設計需重新檢視以維持遊戲公平性。
活動反應超限模式改版後玩法被批評變得無趣且寶石消耗後缺乏彈性，活動設計未能提升玩家興趣，反而引發負評。
