本週社群重點洞察
遊戲體驗配對機制是本週最大爭議點，玩家強烈不滿段位差距過大（星耀配到黃金鉑金）、人機充斥、低齡玩家氾濫，加上檢舉系統形同虛設，導致遊戲環境品質崩壞；角色平衡問題也持續惡化，需團隊優先處理配對邏輯與檢舉機制，否則將加速玩家流失。
Bug回報斷線重連機制設計不良導致玩家被阻擋進場並遭扣分，且勝場積分異常未增加的問題頻繁出現，嚴重影響排位體驗；玩家認為應優先修復現有Bug再推出新內容，建議技術團隊盡速檢視斷線處理邏輯與積分結算系統。
活動反應槓桿活動被批評設計不公平、開啟後必輸，玩家認為活動反而加速輸分；另有玩家期待復刻洛倫星際議會皮膚，但對戰後寶箱獎勵品質低劣表達不滿，活動整體未能點燃正面熱度。
付費體驗玩家認為角色建模品質與定價嚴重不符，並指責遊戲存在誘導儲值的詐騙行為，配合檢舉無效等問題，付費意願與品牌信任度已降至極低點，需公關與營運團隊立即介入改善。
