本週社群重點洞察
遊戲體驗玩家集中抨擊配對與排位機制，認為系統刻意操控勝率、安排強敵弱隊友，部分玩家甚至因長期無法配對或被鎖帳號而呼籲他人停止消費，已嚴重影響遊戲公平性認知與玩家信任度。
Bug回報錯誤代碼1999-1導致大量玩家無法登入，改版後頻繁出現閃退、卡頓、安全圖片無法顯示等技術問題，即使高階設備也無法避免，顯示更新後優化嚴重退步，需立即修復。
客服問題帳號安全保障不足導致盜用與遺失問題頻傳，部分玩家帳號遺失長達半年仍未找回，檢舉機制也存在未查證即處罰、無法檢舉AI玩家等缺陷，客服處理效率與機制公正性亟待改善。
活動反應進擊的巨人聯名活動獲高度讚揚並成功召回玩家，但同時有玩家批評獎勵造型設計粗糙、誠意不足，顯示活動內容品質落差影響整體評價。
付費體驗改名卡僅能透過儲值購買且無法使用遊戲內貨幣兌換，被玩家視為過度斂財，付費機制設計缺乏彈性引發不滿。
