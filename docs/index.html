本週社群重點洞察
•**配對機制嚴重失衡為最大痛點**：星耀配到黃金、冠軍賽遇鑽石對絕士的段位落差問題大量出現，單排對組隊的不公平配對持續引發強烈不滿，87則回饋中73則為遊戲體驗類投訴。
•**檢舉系統形同虛設引發信任危機**：掛機、辱罵、惡意送頭等行為檢舉後未見有效懲處，敏感詞過濾機制不足導致言語騷擾無法成功舉報，多位用戶直指官方「只顧圈錢不解決問題」。
•**槓桿活動設計引發負面反應**：開啟槓桿後勝率異常降低被質疑為「加速輸分」機制，活動公平性遭受質疑，顯示付費/活動設計可能影響核心matchmaking體驗。
•**遊戲環境惡化警訊明顯**：世界頻道充斥色情不雅內容、低齡玩家缺乏管制、人機充斥被視為「遊戲衰亡象徵」，多則留言建議加強年齡管制與社群管理以維持長期健康度。
