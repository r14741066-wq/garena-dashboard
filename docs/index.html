本週社群重點洞察
遊戲體驗本週最嚴重問題集中於匹配機制與隊友素質，玩家普遍反映配對不平衡導致連敗，加上電腦玩家、外掛、掛機問題嚴重，已造成玩家流失；檢舉機制形同虛設更加劇不滿情緒，需立即優化匹配演算法並加強作弊偵測。
Bug回報技術問題涵蓋遊戲卡頓、活動預約錯誤、英雄技能顯示異常及回歸帳號無法登入等多方面，特別是高階設備仍出現嚴重卡頓，顯示底層優化不足，建議優先修復影響玩家留存的登入與卡頓問題。
付費體驗玩家認為遊戲定價過高且內容不符價值，元寶幣商品更新緩慢讓付費玩家感到被忽視，加上遊戲體驗差勁使付費意願降低，需重新評估定價策略並加速虛擬商品更新頻率。
活動反應回歸活動限制過多反而造成反效果，玩家期待特定英雄新造型且希望有免費或可兌換選項，顯示活動設計未能有效刺激玩家參與熱情。
客服問題檢舉系統以「未查證」為由拒絕處理，讓玩家感受不到官方對遊戲環境維護的決心，嚴重削弱玩家對平台公正性的信任。
