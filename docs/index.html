本週社群重點洞察
遊戲體驗配對機制是玩家最大痛點，普遍抱怨系統刻意分配低勝率隊友導致遊戲體驗極差，長期未處理恐加速玩家流失；建議優先檢視matchmaking演算法並對外說明機制邏輯。
Bug回報技能觸控失靈、誤判掛機、錯誤代碼1999-1等問題集中爆發，嚴重影響正常遊玩且導致玩家被錯誤懲處；需技術團隊緊急修復並對受影響玩家進行補償。
客服問題帳號安全漏洞、帳號遺失半年未解決、檢舉機制無法查證回放等問題突顯客服處理能力不足，嚴重損害玩家信任；需強化帳號保護機制與客服回應效率。
付費體驗玩家批評造型定價過高品質不符、改名卡強制儲值購買，顯示付費機制設計引發「過度斂財」負評；建議檢討定價策略並開放部分功能使用遊戲內貨幣。
活動反應進擊的巨人聯名活動獲得高度正面評價，玩家對場景與角色設計表示驚喜並期待後續合作；建議加強此類優質聯名活動的宣傳力度並延長活動週期。
