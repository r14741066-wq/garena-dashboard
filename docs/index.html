本週社群重點洞察
遊戲體驗配對機制與隊友素質是本週最大爭議點，玩家普遍認為系統匹配到缺乏基本意識的隊友（送頭、不懂遊戲機制），加上角色平衡問題（愛麗絲過強、艾連改動無感），導致課金玩家與回歸玩家的遊戲體驗極差，流失風險高。官方需優先檢視配對演算法、加強新手教學機制，以及重新評估角色強度平衡。
客服問題帳號登入問題引發玩家不滿，包括臉書停用導致無法登入、長期未登入帳號遭鎖定等狀況，玩家認為官方推卸責任給第三方平台而不提供有效解決方案，對過往課金投入可能損失感到憤怒，需建立更完善的帳號救援機制與多元登入方式。
Bug回報遊戲開啟後持續當機的技術問題嚴重影響遊戲進行，需技術團隊緊急排查修復。
